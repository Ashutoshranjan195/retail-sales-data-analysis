# Before you discuss this project in an interview

- [ ] Run `python analysis.py` yourself.
- [ ] Explain why dates and numeric columns are parsed explicitly.
- [ ] Explain the validation rules and what the quality report measures.
- [ ] Explain the difference between revenue by category and units sold by product.
- [ ] Run at least two SQL queries yourself and explain `GROUP BY`, `SUM`, and `ORDER BY`.
- [ ] Read `outputs/run_summary.txt` and explain the findings without claiming they represent a real company.
- [ ] Change one query or chart and rerun the analysis.
- [ ] Be clear that the dataset is synthetic practice data.

Retail Sales Data Analysis | Python, pandas, SQL, SQLite, Matplotlib
